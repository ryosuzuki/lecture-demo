# Agent Systems Lab

Six deterministic, browser-only interactive teaching simulations for the September 23, 2026 lecture on generative-AI agents.

Each experiment computes its displayed state from user controls. The system trace is explicitly labeled as an instructional trace, not private model reasoning. No API, account, network request, or build step is required.

Open `index.html` through any static HTTP server. See `TEACHING-GUIDE.md` for classroom prompts and distinctions.
