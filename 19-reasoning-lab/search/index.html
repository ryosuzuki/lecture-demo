Data & model provenance. Exact chunks are selected from Ryo Suzuki’s e-commerce teaching dataset (GitHub, accessed 2026-09-16). Embeddings are computed in your browser by Xenova/all-MiniLM-L6-v2 through Transformers.js. Model card lineage: sentence-transformers/all-MiniLM-L6-v2. First use downloads the model and JavaScript from the network (roughly tens of MB); the browser cache usually makes later loads faster. If the download fails, the lab reports an error—there is no simulated “semantic” fallback. Plotly provides the 3D view. No text is sent to a hosted inference API.
