# Continuous Thoughts walkthrough — instructor script

**Teacher question:** Must every intermediate computation become a word?

1. Identify the recorded real run and its 768D hidden states from a public Coconut replication checkpoint.
2. Step through three states. Explain that the previous final hidden state becomes the next input embedding.
3. Inspect numerical components and change the displayed dimension window.
4. Point to the generated answer and token probabilities, which appear after the latent loop.
5. Ask: *Can we name what a point “means” from its 3D location?* No—the PCA axes are fitted for this run.
6. Distinguish the intermediate token probe from a generated token.

**Teaching boundary:** The PCA path is a visualization of measured states, not a verbal proof or transparent explanation. Probe words were neither generated nor fed back.
