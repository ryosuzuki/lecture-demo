What Is Real? · Model and Sources

All displayed states are 768-dimensional measured activations from an actual GPT-2-based Coconut replication checkpoint. Recorded examples replay actual inference; they are not animations of fabricated numbers. Live mode runs the same weights on this computer.

Checkpoint: bmarti44/coconut-curriculum-checkpoints, coconut/checkpoint_49. Third-party replication, not the original authors' trained weights. We do not independently endorse its benchmark claims.

Method: Hao et al., Training Large Language Models to Reason in a Continuous Latent Space. The previous final hidden state is inserted as the next input embedding. No token is decoded between latent steps. This model was trained for synthetic logical questions; it is not a general-purpose assistant.

PCA is fitted separately to each run. Nearby points need not mean similar thoughts, and paths across different runs cannot be compared in a common coordinate frame. More latent steps are not guaranteed to improve the answer.
