# Vision Lab — 20 interactive experiments

[Open the demos](https://ryosuzuki.github.io/lecture-demo/22-vision-lab/) · [59-second walkthrough](https://ryosuzuki.github.io/lecture-demo/22-vision-lab/walkthrough.mp4)

CNNs, vision transformers, detection, CLIP and diffusion. Runs entirely in the browser without APIs, model downloads or dependencies. Each experiment has a prediction prompt, parameter control, calculation and model-boundary note.

These are explanatory toy models, not pretrained model inference or an exact reproduction of 3Blue1Brown videos. Sources are linked inside the application.
