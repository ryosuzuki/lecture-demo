Teaching through 3D interaction

Five recordings of actual Chrome interactions, with English captions and no audio. Recommended: Value addition → Q/K, then the overview.

15–20 minute teaching sequence: Next-token task (1 min) → semantic directions (3) → overview (2) → Q/K (4) → values (4) → multi-head (2). First ask students which controls will change reading proportions.

A supplementary interactive 3D reconstruction of the source diagrams. These are five spatial explanations, not five independent complete replicas or exact copies of all effects.

1 · Follow the Transformer into depth

Open this view ↗

Say:Each vertical bundle is one token; depth represents processing stages. Attention mixes across positions, while the MLP computes position-wise. The final position predicts the next token.

Do:Orbit → Expand to 0% → Animate → select forest.

Emphasize:This is a token-position × component × processing-stage diagram, not a three-dimensional semantic space. Intermediate activations are illustrative.

3 · What to send: values and residuals

Do:Expand to 0% → orbit → Reset view → Animate → strengthen only the blue Value.

4 · Separate different reading patterns

Open this view ↗

Say:Different Q/K/V produce different updates from the same input. Multiple heads can capture relationships in parallel.
