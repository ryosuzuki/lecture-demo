Suggested lecture sequence

A 25–35 minute sequence: generation loop → embeddings and dot products → mole/Eiffel context → fluffy/blue/creature Q/K → softmax and masking → adding values → multiple heads. Show input and output before opening attention.

  1. Predict → sample → append: Connect prediction to generation first. “Adding a word creates the next input.”
  2. Embedding matrix: Click a word to retrieve its column. “The same mole starts from the same column.”
  3. king / queen → dot product: Prepare difference vectors and dot products. Do not claim an exact match to queen.
  4. mole → Eiffel tower: Context changes update directions.
  5. fluffy / blue / creature → Query → Key → Dot product: “Whose information do we read?” Select the creature column and retain the same source words.
  6. softmax → mask: Show normalization to 1, then mask future positions with −∞.
  7. Value → Weighted sum → Residual addition: Separate where to read from what is received.
  8. Multiple heads → Output matrix: Finish with parallel heads and combination. There is no need to show all 96 heads at the start.
