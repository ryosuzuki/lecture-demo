透明性について

何を描き、何を確認したか。

Transformer の Attention を、6章・150秒の Three.js アニメーションとして説明する独自の日本語教材です。3Blue1Brown の説明的な数式アニメーションと、下記の参考映像の空間演出を参考にしました。原作の完全再現や、特定の学習済みモデルの可視化ではありません。

操作

読み込み後に無音で自動再生します。OS の「視差効果を減らす」設定では停止から開始します。章ボタンや時間バーで移動すると一時停止。Space で再生／停止、左右キーで5秒シーク。「視点を動かす」でドラッグ回転とズームを有効にし、「視点を戻す」で演出カメラに復帰します。

右側（モバイルでは下側）の Query・head・温度・マスク・Value 倍率は、その場で再計算されます。「行列と計算値を見る」で全入力、変換行列、スコア、重み、出力を確認できます。マイク、ログイン、外部推論 API は使いません。

数値の意味

量形状この教材での意味
X4 × 3位置情報を含むと仮定した、手で設定した入力
WQ / WK3 × 2head ごとに異なる固定行列
Q / K4 × 2X と行列の実際の積。2成分を同倍率で矢印へ
WV / V3 × 3 / 4 × 3変換後の「猫」の行だけに倍率介入
A4 × 4行が Query、列が Key。各行の和は1
O = AV4 × 3加重された Value の和
Concat / WO4 × 9 / 9 × 33 head の出力を連結し、3成分へ再投影
Norm / MLP構造のみ数値計算・学習・次トークン生成は実装していません
Q = XWQ,  K = XWK,  V = XWV
S[i,j] = dot(Q[i], K[j]) / sqrt(2)
L[i,j] = S[i,j] / temperature + mask[i,j]
A[i,:] = softmax(L[i,:])
O = AV
X' = X + Concat(O_head1, O_head2, O_head3) WO

マスクは j > i で −∞、それ以外は0。softmax は最大値を引いて安定化しています。温度は分布を探索する教材用の介入で、標準 Attention の必須追加パラメータではありません。Value の倍率は全 head の「猫」の行に適用されます。表示は丸めますが計算は JavaScript の倍精度です。

初期設定（head 1、Query「眠る」、温度1）では q = [0.92, 0.82]、k猫 = [0.99, 0.15]、q·k猫 = 1.0338。注意重みが大きいことを、言語学的な正しさや因果的重要性とは解釈しません。この値は学習したものではありません。

追加の場面レビューと対応関係

初回の60枚に加え、3本の実MP4全体から ffmpeg の fps=1/2 で約2秒ごとの代表画像を抽出。量子198枚、バイバイン30枚、オプション24枚、計252枚を時系列のコンタクトシートで目視しました。全時間にわたる場面レビューですが、連続視聴・全フレーム確認ではなく、短い動きや切り替わりは抜ける可能性があります。

参考の場面（概略秒）教材への対応再現していない部分
量子 24–64：粒子 → 波 → 反射／透過。106–160：点の蓄積 → 分布。376–392：冒頭へ戻る一場面一論点、Q/K → 割合 → Value の段階化、意味ごとの色。映像に集中する表示を追加原動画の現象シミュレーション、ナレーション、カット単位の時間設計、冒頭への循環構成
バイバイン 6–16：反復、16–32：地球／太陽との比較、42–54：銀河から接近数値と3D形状を併記し、カメラで計算の注目点を変える天体規模の連続ズーム、大量オブジェクト、写実的な質感
オプション 4–14：データを立体化、14–24：面を分解、24–34：小さな寄与を追う、34–44：全体へ戻る注意行列の柱、選択QueryのValue寄与、複数headから全体へ。表示を広く使う集中モード面が連続的に分離・再結合するカット、寄与を追う長いカメラ軌跡

3本の全音声を16kHzモノラルに変換し、キャッシュ済みのローカル Whisper large-v3-turbo / MLX でASRを実行しました。量子動画は34区間の日本語出力を確認し、概略の章構成を照合しましたが誤認識があり、校訂済み全文ではありません。短い2本は汎用的な英語の文や動画長を超える時刻が出たため、内容の証拠として不採用です。直接の聴取・音質評価は未実施。原音声・原映像・全文文字起こしは転載していません。
