Transformerを「動かしながら」説明する

18分の導入 → 実際のGPT-2を5分 → 理解チェック。授業画面は英語、教員向けガイドは日本語。

操作動画（日本語字幕・音声なし）

実際のブラウザを操作した約2分の短縮リハーサルです。授業では各問いの後に20〜30秒待ち、学生に予想してもらってください。

0–3分：意味はどこにある？

操作：Context → Reveal context → Finance context → Reveal context。

問い：“What does bank mean here? Which word tells you?”

説明：「bankというトークンの出発点は同じ。でも川の文脈とお金の文脈では、周囲から受け取る情報が違う。Transformerはその情報の受け渡しを繰り返します。」

先に「単語→ID→埋め込み」を30秒で説明。IDは住所のようなインデックス、埋め込みは学習された数値ベクトル。この2つを同一視しない。

3–7分：QとKは照合する

操作：Match Q × K → スライダーをRiverからFinanceへ動かす。

問い：“Which weight will grow if I move this query?”

説明：「Qは今ほしい情報を照合するためのベクトル。Kは各位置が照合に使うベクトル。内積で相性のスコアを計算し、softmaxで合計1の重みにする。Vはまだ足していない。」

第1章は概念図。第2〜3章では両方の手がかりがある4トークン「river money the bank」に切り替え、Qへの介入を比べる。全文をモデルで解釈しているわけではない。Q/K/Vをhashの完全一致検索として説明しない。学習済みの別々の行列を入力に掛けて作る、連続的なsoft lookup。『質問』『名札』は役割の比喩であり、自然言語の質問が内部にあるわけではない。

7–11分：重みではなく、情報が動く

操作：Mix the values → スライダーを0から1 → Finance query。

問い：“What gets added: the keys, or the values?”

説明：「先ほどの重みをVに掛けて足す。そのメッセージが元のbankに加わる。黄色のベクトルが、文脈を受け取った表現です。」

ここで初めて式：Attention(Q,K,V)=softmax(QKᵀ/√dₖ + mask)V。各記号を今見た動作に対応づける。実モデルは複数ヘッドの出力を結合してW_Oで射影し、残差経路・正規化・MLPを通す。ヘッドの仕事は学習され、人が「文法ヘッド」などと指定するものではない。

11–14分：未来を見たらカンニング

操作：No looking ahead → bankを選ぶ → mask OFF → ONに戻す。

問い：“Can bank look at quiet when predicting what comes next?”

説明：「GPTは今までの位置と自分自身を見られる。未来はsoftmaxの前に−∞にする。学習では多くの位置を並列計算できるが、通常の生成では次の1トークンを足して繰り返す。」

maskの有無をTransformer全般とGPTの違いに結びつける。エンコーダ型には双方向attentionもある。位置情報は別途必要。

14–18分：予測と学習は別の操作

操作：Predict & learn → River / Finance → temperature → Sample → Train。

問い：“Did changing temperature teach the model anything?”

説明：「温度は確率分布とサンプリングを変えるだけ。学習は正解の次トークンと比べたlossの勾配でパラメータを変える。大量の文章がそれ自体で問題と正解を提供する。」

この章は別の文完成の説明用readout。前章の全トークンを処理した実GPTの続きではない。Trainは出力biasの一つだけを更新する。1例のloss低下は一般化を保証しない。

18–23分：toyから実モデルへ

  1. Transformer Explainer：ブラウザ内GPT-2。短い文を入力し、token → embedding → attention → outputを今の5章と対応づける。最初から全体を拡大して説明せず、Q/Kの照合とVの受け渡しを一つずつ追う。モデルのダウンロードがあるので授業前に開く。
  2. LLM Visualization：全体の立体的な計算構造を見せるのに向く。初学者への最初の説明には情報量が多いので、最後に「これを何層も積む」の確認用に。
  3. 3Blue1Brown: Attention：ベクトルに意味が乗り、文脈を受け取る直感の予習・復習に。今回の教材はオリジナルの描画・実装で、動画を転載したものではない。

おすすめ：このデモで因果関係をつかむ → Transformer Explainerで本物を見る、の二段構成。toyをなくすより、どこを簡略化したかを明示して実モデルへの橋を架ける。

最後の理解チェック

  1. Kだけを変え、Vを固定すると？ → 重みが変わり、混ざる量が変わり得る。
  2. Vだけを変え、Q/Kを固定すると？ → 重みは同じ、届く情報が変わる。
  3. temperatureを変えるとQ/K/Vが学習される？ → されない。
  4. 次トークンの正解ラベルは誰がつける？ → 文章中の次のトークン自身。

数値モデルの範囲

この教材はGPTの学習済み重みを使用しません。4つの説明用K/V、2次元Q、softmax、Vの加重和、単位出力射影、残差の加算、4語のreadoutを計算しています。Qの変更は介入です。第4章の行列は独立した位置スコア例です。実モデルの文脈処理を完全再現しているわけではありません。

入力埋め込みからQ/K/Vを学習する過程、多層MLP、正規化、位置符号化は概説のみ。『意味がひとつの軸に対応』『Attentionは人間の説明そのもの』『全ヘッドに決まった文法役割』とは教えないでください。
