# Attention Context — 授業リハーサル台本

約5分。context版の実操作。音声：Microsoft Edge ja-JP-NanamiNeural。独自の日本語台本。

## 0:00 授業の問い：割合と内容を分けよう

この動画では、context版を実際に操作します。問いは、読む割合と、運ぶ内容は同じものか。学習済みモデルではなく、四つの語を使う説明用の模型です。

## 0:18 第2章：creature → Query [2,2]

第2章を押し、シークバーを進めます。読む側は creature。入力はゼロ、ゼロ、イチ。行列を掛けると、黄色の Query は、ニ、ニになります。

## 0:35 読む側を fluffy に変更

fluffy を押してください。同じ行列でも入力が違うため、Query はゼロ、ゼロになります。この模型では、名詞の creature が形容詞を探すように設計しています。

## 0:53 第3章：q・k = 4、まだ確率ではない

creature に戻し、第3章へ。fluffy との内積は、ニかけるニ、足す、ニかけるゼロで、ヨン。blue ともヨンです。ルートニで割りますが、まだ確率ではありません。

## 1:11 第4章：符号付きスコア

第4章では、バーを動かして計算の段階を見せます。最初はスコア。黄色の行が読む側で、各列が情報源です。負の値もあり、合計はイチとは限りません。

## 1:30 未来マスク：softmaxより前

読む側を fluffy にして、マスクの段階へ進めます。まだ先にある blue と creature は、マイナス無限大です。未来を隠す操作は、ソフトマックスより前です。

## 1:47 指数化：exp(−∞) = 0

もう少し進めると、指数化です。マイナス無限大はゼロになるので、未来の語は分母にも入りません。大きな値を見やすくするため、この段階の柱の高さは対数表示です。

## 2:06 正規化：fluffy の行は 0.5 / 0.5 / 0 / 0

最後は正規化。右の読む割合を見てください。fluffy の行では、見えている二語が半分ずつ。各行の合計はイチです。Query がゼロなので、ここでは同じスコアになります。

## 2:26 「未来を隠す」をOFF：4語に25%ずつ

未来を隠すチェックを外します。四語すべてが四分の一になりました。これは未来の情報を読む比較実験です。因果的な生成では、チェックを戻して未来を遮断します。

## 2:44 第5章：e + Δe = e′

チェックを戻し、creature と第5章を選びます。白が元の表現、色付きが重み付きの Value、赤が更新後。右の割合と、赤い矢印の到着点を一緒に見ます。

## 3:03 fluffy Value倍率 1 → 0：Aは不変

ここで予想してください。fluffy の Value 倍率だけをゼロにしたら、読む割合も変わるでしょうか。操作すると、割合は同じまま、ふわふわ方向の寄与だけが消えます。

## 3:20 倍率 0 → −1：運ぶ向きだけ反転

さらに、マイナスイチへ動かします。fluffy の寄与は逆向きになり、赤い到着点も移ります。青さの成分と、読む割合は変わりません。小さな a の寄与は残っています。

## 3:39 倍率を1に戻す：割合Aと内容Vは別

倍率をイチに戻します。ここでまとめます。Query と Key が読む割合を決め、Value が運ぶ内容を決める。この操作は Value だけへの介入で、入力全体を書き換える実験ではありません。

## 3:59 第6章：Valueの 3 → 2 → 3

第6章の上段を見ます。fluffy の三成分を、ダブリューブイで二成分へ。ダブリューアップで三成分へ戻します。これは元データの完全復元ではなく、渡す更新を作る写像です。

## 4:18 Headを切り替え、異なる写像を比較

Head を切り替えます。上段の数値と、右の読む割合が変わります。下段の三つは各 Head の注意行列です。それぞれの更新を足す計算は、連結してダブリューオーを掛ける計算と一致します。

## 4:39 生徒への確認：A一定でも e′は変わる？

最後に、生徒に説明してもらいましょう。読む割合が同じでも、更新後の表現が変わるのはなぜか。この教材は Attention の内部に限定し、学習、ノルム、エムエルピー、文章生成は実装していません。
